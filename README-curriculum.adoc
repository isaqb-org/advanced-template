== About this curriculum

This repository contains the source of the iSAQB^(R)^ Advanced Level (CPSA-A) curriculum
*<FULL MODULE NAME>* (module *<MODULE-SHORT>*).

The curriculum is written in AsciiDoc and built into versioned *PDF and HTML* output in
*German (DE)* and *English (EN)*. It was created from the
https://github.com/isaqb-org/advanced-template[iSAQB Advanced Level template].

== Released documents
The latest released HTML and PDF documents (German and English) are published via GitHub
Pages at https://public.isaqb.org/REPO-NAME[public.isaqb.org/REPO-NAME].

They are produced by CI on each release. Pre-rendered translations in other languages
(if any) live in `docs-ext/` – see `docs-ext/EXTERNAL_DOCUMENTS_README.adoc`.

== How to build locally
Prerequisite: a locally installed JDK 21 or higher. +
Clone the repository including its submodules:

[source,shell]
----
git clone git@github.com:isaqb-org/REPO-NAME.git --recursive
----

If you already cloned without `--recursive`:

[source,shell]
----
git submodule update --init --recursive
----

Build all languages and formats:

[source,shell]
----
./gradle-tools/gradlew buildDocs
----

The results are written to `build/` (PDF and HTML per language) together with an
`index.html` overview page. To build a single output use e.g.
`./gradle-tools/gradlew pdfDE`; run `./gradle-tools/gradlew tasks` to list all
available render tasks.
